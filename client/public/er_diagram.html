4.5 Database Design (Data Dictionary)

The relational schema implied by the ER diagram is detailed below, table by table, with field names, data types, and descriptions.

4.5.1 Patient
FieldTypeDescription
patient_idINT (PK, AUTO_INCREMENT)Unique patient identifier
nameVARCHAR(100)Patient's full name
dobDATEDate of birth
genderVARCHAR(10)Male / Female / Other
contact_noVARCHAR(20)Primary contact phone number
blood_groupVARCHAR(5)Blood type (e.g., A+, B+, O-)
4.5.2 Doctor
FieldTypeDescription
doctor_idINT (PK, AUTO_INCREMENT)Unique doctor identifier
nameVARCHAR(100)Doctor's full name
specializationVARCHAR(100)Medical specialty (e.g. Cardiology)
contact_noVARCHAR(20)Contact phone number
department_idINT (FK)References Department(department_id)
4.5.3 Department
FieldTypeDescription
department_idINT (PK, AUTO_INCREMENT)Unique department identifier
dept_nameVARCHAR(100)Department name
head_doctor_idINT (FK)References Doctor(doctor_id)
4.5.4 Appointment
FieldTypeDescription
appointment_idINT (PK, AUTO_INCREMENT)Unique appointment identifier
patient_idINT (FK)References Patient(patient_id)
doctor_idINT (FK)References Doctor(doctor_id)
dateDATEScheduled consultation date
time_slotVARCHAR(20)Assigned time slot
statusVARCHAR(20)Scheduled / Completed / Cancelled
4.5.5 Ward & Admission
FieldTypeDescription
admission_idINT (PK, AUTO_INCREMENT)Unique admission record ID
patient_idINT (FK)References Patient(patient_id)
ward_idINT (FK)References Ward(ward_id)
admit_dateDATETIMEPatient admission timestamp
discharge_dateDATETIMEPatient discharge timestamp
4.5.6 Prescription & Bill
FieldTypeDescription
prescription_idINT (PK, AUTO_INCREMENT)Unique prescription ID
bill_idINT (PK, AUTO_INCREMENT)Unique bill / invoice ID
appointment_idINT (FK)References Appointment(appointment_id)
amountDECIMAL(10,2)Total itemized billed amount
payment_statusVARCHAR(20)Paid / Pending / Refunded
